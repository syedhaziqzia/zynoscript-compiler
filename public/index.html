Syntax & Grammar Rules

          

            
    
              
  • Statements are line-delimited (semicolons ; are optional)
    • 
              
  • Every complete program concludes with halt
    • 
              
  • Variables can be explicitly typed: let whole a := 5
    • 
              
  • Variables can also be inferred from values: let x := 5
    • 
              
  • Conditional statements support optional parentheses around conditions: whenTrue x <<= y
    • 
              
  • Single statements can be written with or without enclosing braces { }
    • 
              
  • Explicit type casting uses x as~ whole (converts between whole, part, phrase, flag, and mark).
    • 
              
  • Single-line comments begin with // and run to the end of the line.
    • 
              
  • Multi-line block comments open with /~~ and close with ~~/; they may span any number of lines.
    • 
              
  • Comments are removed by the lexer, so they never affect tokens, the AST, or program output.
    • 
            

          

        


        

          
Comments (// & /~~ ... ~~/)

          

            
// single-line comment: ignored until end of line
let whole total := 10   // trailing comment after code

/~~ multi-line block comment:
    begins with /~~ and spans multiple lines
    until closed with ~~/
beam total
halt

            
Custom operators may not contain //, /~~, or ~~/, so comments always stay unambiguous.

          

        


        

          
Explicit Type Casting (as~)

          

            
let part rate := 19.75
let whole units := rate as~ whole      // 19.75 -> 19
let phrase label := units as~ phrase   // 19 -> "19"
let whole parsed := "42" as~ whole     // "42" -> 42
let mark grade := 65 as~ mark          // 65 -> 'A'
let flag ok := 1 as~ flag              // 1 -> true

            
Supported casts: whole ↔ part, any → phrase, phrase → whole/part (checked at runtime), flag ↔ whole (0/1), and mark ↔ whole (character code).
